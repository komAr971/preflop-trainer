# Preflop Trainer — план

Согласован 2026-11-15 (grill-сессия). Изменения решений — только через обновление этого файла.

## Цель
PWA для заучивания префлоп-чартов NLHE 6-max 100bb с загрузкой своих чартов.
Один пользователь, без бэкенда, данные локально (IndexedDB) на каждом устройстве.

## Стек
- TypeScript strict, React, Vite
- Zustand (состояние), Dexie (IndexedDB), Zod (валидация импорта)
- SVG-стол + Motion (анимации), Radix UI (кнопки/диалоги)
- i18next + react-i18next: RU/EN, язык по умолчанию из браузера, переключатель в настройках
- vite-plugin-pwa (офлайн, установка на телефон; иконки рендерит `scripts/make-icons.mjs` из `public/icon.svg`)
- Тесты: Vitest (логика), Testing Library (компоненты), Playwright (e2e, включая мобильный viewport)
- TDD: сначала тест, потом код. Покерная логика — чистые TS-модули без React (`src/core`)
- CI: GitHub Actions — typecheck → lint → тесты → деплой на GitHub Pages

## Предметная область
- Формат: 6-max, 100bb, кэш
- Споты v1: RFI; против опена (колл/3-бет/фолд, включая защиту ББ); против 3-бета (колл/4-бет/фолд)
- Споты v2: против 4-бета, против лимпа
- Чарт хранит частоты каждого действия для каждой из 169 рук (смешанные стратегии)
- Сайзинги (опен 2.5bb, 3-бет IP 3x / OOP 4x и т. п.) хранятся в метаданных чарта
- Названия чартов не переводятся

## Ввод чартов
- Внутренний формат — JSON приложения, через него идут импорт/экспорт
- Редактор-сетка 13×13
- Вставка строки диапазона в стиле PioSolver/GTO Wizard: `AA,KK,AKs:0.5,AJo:0.25` (одна строка на действие)
- Стартовый набор: базовые диапазоны NL2–NL10 (сверяет пользователь)

## Тренировка
- Режим «Раздача»: графический стол (SVG), герой всегда внизу, четырёхцветная колода, ставки фишками
- Смешанная рука: ответ верен, если частота действия ≥ 25% (порог настраивается)
- Выбор рук: 70% пограничных (сосед по сетке имеет другое действие), доля настраивается
- Интервальное повторение ошибок

## Размер рейза (добавлено 2026-11-16)
- Панель размера как в покерных клиентах: ползунок от минимального рейза до 100bb, −/+, поле bb; кнопка показывает выбранный размер («3-бет до 9bb»), R или Enter — рейз
- Верное действие с неверным размером = ошибка (идёт в повтор); в разборе формула: «3-бет без позиции: 2.5bb × 4 = 10bb»
- Размер берётся из сайзингов чарта; допуск в настройках (по умолчанию 0 — точно); олл-ин вводить не нужно; можно выключить

## Телефон (добавлено 2026-11-16)
- Навигация в бургер-меню (там же «Нарисовать чарт» и версия)
- Экран тренировки — ровно один экран: стол занимает оставшуюся высоту, внизу панель размера и одна строка кнопок (рейз — под полем размера); панель размера видна всегда (неактивна при олл-ине), чтобы раскладка не прыгала
- Разбор ошибки — выезжающая снизу панель с прокруткой; поле размера выделяет значение при фокусе

## Разбор ошибки (добавлено 2026-11-16)
- При ошибке: причина (рука не в диапазоне / частота ниже порога / не тот интервал рандомизатора / только размер), ширины диапазонов спота, граница рядом (соседние руки, где выбранное действие играется), чарт спота с обведённой рукой

## Встроенные чарты
- Базовый 6-max 100bb и три чарта Greenline 2026 (стандарт, RFI узко, RFI широко) со слайдов видео — источник и расхождения в `docs/sources/greenline-2026.md`

## Статистика
- Точность по каждому споту (позиция × ситуация)
- Тепловая карта ошибок 13×13
- Серия дней, цель дня (по умолчанию 100 рук). День засчитывается в серию, если цель дня выполнена; сегодняшний день не рвёт серию, пока он не закончился
- «Выучено»: точность ≥ 90% за последние 200 рук в споте (оба числа настраиваются)

## Звуки
- События: раздача карт, ставка фишками, верный ответ, ошибка
- Синтез через Web Audio API (без аудиофайлов и лицензий), работает офлайн
- Все настройки (порог, доля пограничных, «выучено», цель дня, звук) — экран «Настройки», хранятся в IndexedDB
- В настройках: вкл/выкл (по умолчанию вкл) и громкость; выбор запоминается

## Интерфейс
- Языки RU/EN; позиции всегда латиницей (UTG, MP/HJ, CO, BTN, SB, BB), действия переводятся
- Вторая позиция показывается как MP (по умолчанию, как на GipsyTeam) или HJ (как в GTO Wizard) — переключатель в настройках; в файлах хранится HJ, импорт принимает оба

## Этапы
Без дат. Переход к следующему этапу: текущий задеплоен, все тесты зелёные, пользователь принял результат на телефоне и ПК.

- **A**: модель данных, парсер диапазонов, стартовые чарты, графический стол, режим «Раздача», i18n, CI/деплой
- **B**: редактор-сетка, импорт/экспорт JSON и строк диапазонов, повторение ошибок
- **C**: статистика, тепловая карта, серии, «выучено», звуки, полировка под телефон (крупнее стол и подписи, плашки не налезают на борт)
- **v2** (порядок и детали согласованы 2026-11-15):
  1. Рандомизатор 1–100: интервалы рейз → колл → фолд; «Смешанные руки: порог / рандомизатор» в настройках (по умолчанию порог) — готово
  2. «Нарисуй чарт»: кнопка на экране тренировки, спот на выбор или случайный, пустая сетка и кисти; «Проверить» → % верных по комбинациям среди значимых рук (играются в чарте или закрашены; пустая сетка = 0%) и сетка различий (тап по клетке — как должно быть); смешанная рука верна при действии ≥ порога; в статистике отдельной строкой «Рисование», в «выучено» не идёт — готово
  3. Против 4-бета: фолд / колл / 5-бет олл-ин (100bb), сайзинг 4-бета из `fourBetX`, 15 спотов, простые чистые стартовые диапазоны (в позиции 5-бет QQ+/AK, колл JJ-TT/AQs; из блайндов 5-бет QQ+/AK или фолд) — готово
  4. Против лимпа: фолд / овер-лимп / изо-рейз (4bb IP, 5bb OOP, настраивается); ББ против лимпа SB — чек / рейз; лимперов может быть несколько: спот = позиция героя × число лимперов (1 / 2 / 3+), при раздаче лимперы случайно садятся на места до героя; изо-рейз +1bb за каждого лимпера после первого; 12 спотов (HJ×1, CO×1–2, BTN/SB/BB×1–3+); сайзинги изо-рейза в чарте (`isoIpBb`, `isoOopBb`, необязательные для старых файлов) — готово

## v3 (grill 2026-11-16)
Порядок: таймер → мультитейблинг → аккаунт → iOS. Каждая тема — свой грилл и своя реализация.
- Аккаунт нужен для синхронизации телефон ↔ ПК и бэкапа; соцфункций (лидерборды, обмен) нет → офлайн-сначала + синхронизация
- Мультитейблинг только на широком экране (от ~900px), на телефоне режим скрыт; тренажёр не держать открытым рядом с клиентом рума (бан софта GG с 01.12.2026)
- iOS: остаёмся на PWA («На экран Домой»), без App Store; довести под iPhone (установка, звук, safe-area)

### Таймер
- Время ответа засекается всегда: от конца анимации раздачи до нажатия кнопки; пауза, пока вкладка скрыта
- На столе полоска под картами героя + секунды, как в руме
- Настройка «Лимит времени»: нет / 5 / 10 / 15 / 30 с, по умолчанию «нет»
- Время вышло = ошибка «время вышло», в очередь повторов, разбор с верным ответом; автофолда нет
- Последние 3 с полоска красная + тихий тик (отдельный переключатель звука)
- Статистика: «Время решения» = медиана; колонка по спотам, общая за сегодня и за всё время; ответы дольше 60 с и таймауты в медиану не входят; у спота счётчик таймаутов; старые попытки без времени — «—»
- Скорость на «выучено» не влияет (вернуться после реальных цифр)
- В «Нарисуй чарт» таймера нет

### Мультитейблинг
- 1 / 2 / 3 / 4 стола — переключатель в шапке тренировки, выбор запоминается; окно уже ~900px → 1 стол (выбор возвращается)
- Раскладка плиткой: 2 рядом, 3–4 сеткой 2×2
- Каждый стол берёт случайный спот из выбора независимо; очередь повторов и счётчик общие
- Верно → стол сам раздаёт через ~0.5 с; ошибка → стол стоит (причина, верное действие, «Почему?»), следующая рука по клику, остальные играют
- Активный стол = ждёт дольше всех, подсвечен рамкой, горячие клавиши на него; мышью — любой; у каждого стола свой таймер
- Полный разбор — панель справа, таймеры остальных столов на паузе
- Одинаковые звуки с разных столов не чаще ~100 мс
- Панель размера на каждом столе полная (ползунок, −/+, поле bb, рейз) — пробуем; если на 3–4 столах тесно, вернуться к компактной

### Аккаунт и синхронизация
- Бэкенд Firebase (Auth + Firestore), тариф Spark; проект на Google-аккаунте пользователя, создаётся по пошаговому мастеру; веб-ключи публичные, защита — правила безопасности
- Вход email + пароль, «Забыл пароль» письмом (Google/ссылка из письма ломаются в iOS PWA)
- Аккаунт необязателен: без входа всё локально, как сейчас; вход в настройках включает синхронизацию
- Синхронизируются попытки, очередь повторов, свои чарты, рисунки, настройки; громкость и число столов — только на устройстве
- Первый вход: попытки и рисунки объединяются без дублей; свои чарты объединяются, совпадение имени → «(2)»; настройки из аккаунта, если есть, иначе с устройства
- Конфликты: последнее изменение побеждает; попытки только добавляются
- «Удалить аккаунт» в настройках: стирает облако и аккаунт, локальные данные остаются
- Для синхронизации нужны глобальные id своих чартов (UUID) вместо автоинкремента
